Kamdoo Mobile Connector

Pair the Kamdoo mobile app with this database by QR code, and show your company's name, logo and colour in the app.

This module is the server side of Kamdoo, a free native mobile app for Odoo that is installed separately on each phone. The app also works without this module, with the usual Odoo login; the module adds QR code pairing and your company's identity, phone notifications.

What it adds

Connect my phone

A new entry in the user menu shows a QR code that the Kamdoo app scans. It holds a one-time token, valid for five minutes, never a login or a password. Administrators also find it in Settings › Kamdoo mobile app.

Your company in the app

The app shows your company's name, logo and colour, read before sign-in from the public route /kamdoo/info. It returns the Odoo and module versions, the database name and the company's name, colour and logo: what the public login page already shows, nothing more.

Touch-friendly screens

When an Odoo page is opened from the app, it gets larger touch targets and a layout suited to a phone screen. Nothing changes for people using Odoo in a browser.

Notifications on the phone

Private messages, mentions and Inbox items reach the phone, end-to-end encrypted. Odoo 14 has no Web Push: this module adds it the way Odoo 17 does (RFC 8291 encryption, RFC 8292 VAPID signature). If the Python cryptography package is missing, a pure-Python implementation of the same algorithms is used.

Your data and external services

  • The app talks directly to your Odoo server. Kamka IT, the publisher, receives none of your business data.
  • Notifications are the one exception. This module encrypts each notification for the phone it is meant for, then sends it to the Kamdoo relay, an external service run by Kamka IT, which forwards it to Apple Push Notification service or Firebase Cloud Messaging. The relay cannot read the content and keeps none of it.
  • Nothing is sent to the relay unless a user has paired a phone and allowed notifications on it. Each user can turn notifications off in the phone's settings at any time.
  • The relay's source code is public: github.com/kamka-ai/kamdoo-relais. Privacy policy: kamdoo.kamka-it.com/privacy.html.
  • No activation key, no account with Kamka IT, no subscription.

Installation and use

  1. Copy the kamdoo_connect folder into your addons path, update the Apps list and install Kamdoo Mobile Connector.
  2. Install the Kamdoo app on the phone.
  3. In Odoo, open the user menu › Connect my phone and scan the QR code with the app.

Requirements: Odoo 14.0, Community or Enterprise. Depends on web, base_setup, mail.

  • The Python requests package (present in the official Odoo images).
